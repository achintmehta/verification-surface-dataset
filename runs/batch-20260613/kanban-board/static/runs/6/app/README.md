# Collaborative Kanban Board

A lightweight real-time Kanban board using Node.js, Express, embedded PGLite, Server-Sent Events, and a Vanilla JS/Vite frontend.

## Development

```bash
npm install
npm run dev
```

- Backend: http://localhost:3000
- Frontend: http://localhost:5173

Board state is persisted under `./data/pglite` by default.
