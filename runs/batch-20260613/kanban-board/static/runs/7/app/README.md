# Collaborative Kanban Board

A small real-time collaborative Kanban board using Express, embedded PGLite, Server-Sent Events, and a Vanilla JS/Vite frontend.

## Run

```bash
npm install
npm run dev
```

- Frontend: http://localhost:5173
- Backend API/SSE: http://localhost:3000

PGLite persists data under `./data/kanban-pglite`.
